# Matteträning

En enkel mobilanpassad webbapp för mängdträning i matematik.

## Nivåer

1. Addition 0 till 1000 utan övergång
2. Addition 0 till 1000 med övergång
3. Subtraktion 0 till 1000 utan växling
4. Subtraktion 0 till 1000 med växling
5. Multiplikation

Öppna `index.html` eller publicera repot med GitHub Pages. På iPhone och iPad kan sidan sedan läggas till på hemskärmen från Safari.
